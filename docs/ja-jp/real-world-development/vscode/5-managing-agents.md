GitHub Copilot をエージェント モードにすると、コードベースを調べ、変更を提案し、ファイルを編集し、コマンドを実行します。VS Code の Copilot Chat では、ツールの呼び出しやファイルの編集をリアルタイムで確認できます。差分をインラインでレビューし、個々の変更を適用または取り消し、フォローアップ プロンプトを送って作業を調整、拡張できます。エディターを離れる必要はありません。

この演習では、次の内容を学習します。

- アクセシビリティ エージェントの作業をリアルタイムで監視する。
- 提案されたファイル編集を確認して適用する。
- セッションの途中でエージェントに指示を追加し、高コントラストとともにライト モードの切り替えも追加する。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタム エージェントは、高コントラスト モードを実装中です。作業中にデザイン チームから、既定のテーマが暗すぎると感じるユーザー向けにライト モードも用意してほしいという追加リクエストがありました。新しい会話を最初から始めるのではなく、既存のセッションに指示を追加して作業を拡張します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが実行する各手順が表示されます。調査したファイル、実行したコマンド、提案された編集を確認できます。ファイルの編集は差分と **Keep** / **Undo** の操作とともにインラインで表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツールの呼び出しを確認します。ファイルの読み取りや編集、実行を求められたターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がインラインで表示されます。
   - **Keep** を選択すると変更を適用します。
   - **Undo** を選択すると変更を元に戻し、エージェントにもう一度作業させます。
4. チャット上部の **Files changed** を開くと、このセッション中にエージェントが変更したファイル全体を確認できます。

> [!NOTE]
> ターミナル コマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してもよいコマンドだけを承認してください。

5. エージェントが高コントラスト モードの実装を完了するまで待ちます。最後に、変更内容の概要が表示されます。

## ライト モードを追加するようエージェントに指示する

高コントラスト モードができたら、同じ会話でライト モードの切り替えを追加します。同じチャット セッションを続けるため、エージェントは前の作業で変更したコンポーネント、スタイルの方法、ローカル ストレージのパターンなどのコンテキストを保持しています。

1. Copilot Chat の入力欄に、次のフォローアップ プロンプトを送信します。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントはすでに行った変更を確認し、ライト モードの追加を提案します。
3. 高コントラストのときと同じように、新しい編集を確認します。差分ごとに **Keep** または **Undo** を選択します。
4. エージェントの方向性が希望と異なる場合 (たとえば、切り替え UI を意図しない方法でリファクタリングする場合) は、チャット入力欄の横にある **Stop** ボタンで停止してから、追加の説明を送ります。

> [!TIP]
> 実行中のセッションに指示を加えると、最初からやり直すより早く作業できます。フォローアップ プロンプトで調整を依頼できます (「CSS を簡潔にし、セレクターの重複ではなく CSS 変数を使用する」)、方向を修正できます (「3 つ目の切り替えを追加せず、既存の設定パネルにライト モードを統合する」)、スコープを広げることもできます (「両方の切り替えにキーボード ショートカットも追加する」)。

## 変更されたファイルをレビューする

作業をコミットする前に、エージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されています。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタム エージェントのアクセシビリティ パターン (ARIA 属性、キーボード操作、セマンティック HTML、ローカル ストレージへの設定保存など) が反映されていることを確認します。
4. 問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェント モードを使って、実行中のセッションを監視し、方向を示しました。ファイルの編集を確認して適用または取り消し、コンテキストを失わずにフォローアップ プロンプトで作業を拡張しました。

このレッスンでは、次の内容を学習しました。

- エージェントの作業をリアルタイムで監視する。
- 個々のファイル編集を適用または取り消す。
- 実行中のセッションにフォローアップ プロンプトを送る。
