[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent) 可在云端异步处理工作。你在 GitHub 上分配任务后，cloud agent 会在后台探索存储库、进行更改并创建拉取请求，让你可以继续处理其他工作。

在这些练习中，你将添加 cloud agent 会遵循的自定义说明，然后分配 GitHub 问题并让它实现任务。你还将查看和使用自定义代理来指导其工作，在代理仪表板中监控并引导会话，最后审查代理创建的拉取请求并迭代优化结果。

## 先决条件

参加本练习前，请确保具备以下条件：

- [ ] 拥有有效的 **Copilot Student、Pro、Pro+、Business 或 Enterprise** 计划的 GitHub 帐户
- [ ] 已为帐户或组织启用 Copilot cloud agent

> [!TIP]
> 没有付费计划？通过 [GitHub Education][callout-student-plan-education] 验证身份的学生可免费使用 GitHub Copilot。**Copilot Student** 计划包括本练习使用的代理、MCP、代码审查和 Copilot CLI 功能，可用于完成所有环境中的练习。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Copilot cloud agent 适用于 **Copilot Student、Pro、Pro+、Business 和 Enterprise**，不适用于 Copilot Free。使用 Copilot Business 或 Enterprise 时，管理员必须为组织启用此功能。

> [!NOTE]
> 本练习不涉及 MCP。要了解如何将 MCP 服务器与 Copilot 搭配使用，请查看 [CLI 练习](../cli/)或 [VS Code 练习](../vscode/)。
