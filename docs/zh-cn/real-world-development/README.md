通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将迭代地规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌游众筹，并以开发者为主题。团队的待办事项已作为 GitHub 问题提交，供你开始处理，其中包括筛选和分页等功能，以及无障碍和编码规范等质量改进。

## 选择工作环境

GitHub Copilot 可以融入你的工作环境。选择最符合你开发方式的环境。每个练习都会从各自的设置步骤开始，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手，体验 Plan 和 Autopilot 模式、说明、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

运行并行代理会话、切换会话模式、协作使用画布，并在桌面 app 中管理 GitHub 问题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 问题分配给异步代理、指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot，直接在编辑器中体验 Copilot Chat agent mode、MCP 服务器和自定义代理。
